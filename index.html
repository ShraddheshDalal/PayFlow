PayFlow — Smart UPI Payment System

Payments made simple. Control made smarter.

Simulation notice: PayFlow is an academic demonstration. Every payment is simulated in the browser; no bank, UPI network or payment provider is contacted and no actual money is transferred.

Objective

Demonstrate a small but complete payment web application, built in iterations and delivered through an automated CI/CD pipeline. It continues the online-payments domain of our earlier UPI case study with independent branding and features.

Simulated payment workflow

  1. Enter recipient name, UPI ID, amount and an optional note.
  2. Details are validated in JavaScript against the demo rules.
  3. Review the confirmation panel and confirm the demo payment.
  4. A reference is generated, the result is shown and history, balance and statistics update together.

Features implemented

  • Dashboard with live balance and transaction statistics
  • Validated Send Money form with field-level errors
  • Confirmation, processing and success/failure states
  • Searchable, filterable, sortable transaction history
  • Transaction detail view and recent recipients
  • Persistent demo data with confirmed reset
  • Responsive, keyboard-accessible interface

Technology stack

  • HTML5
  • CSS3
  • Vanilla JavaScript (ES modules)
  • Node.js & npm
  • node:test
  • ESLint
  • Git & GitHub
  • GitHub Actions
  • GitHub Pages

Agile process

Work was organised as a product backlog of user stories (send money, validate details, view history, reset demo). Each short sprint delivered a working increment, reviewed against acceptance criteria that became automated unit tests. Continuous integration gives fast feedback on every push.

CI/CD pipeline

  1. GitHub
  2. Build
  3. Automated Testing
  4. Code Quality Check
  5. Deployment
